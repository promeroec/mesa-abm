# mesa-abm
Agent-based models of economic phenomena in Python via Colab.
Python-Mesa implementation of the Diamond–Dybvig (1983) model.
This is the Agent-based model inspired by the NetLogo model DDmodelV4.nlogo, in the paper 
"Bank runs, banking contracts, and social networks," 2009, by Pedro Romero.
https://www.researchgate.net/publication/228201003_Bank_Runs_Banking_Contracts_and_Social_Networks
